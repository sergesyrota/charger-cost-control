Charger UI — 5 prototypes

Same functionality as PLAN.md §11, five different ways to organize it. Each has a "Demo scenario" switcher in the corner (charging / waiting / on-but-not-charging / booting / manual override).

1 · Now firstFour destinations (Now, Rules, History, Device) instead of eight tabs. Plain-language hero answer, 24h price strip with predicted next ON, mode control on the home screen. 2 · TimelineAn interactive 24h price/decision chart is the main navigation. Scrub any hour to see what the engine decided and why; a precedence-chain explainer opens each editor. 3 · Plain languageStatus and rules read and edit as sentences with inline tokens, plus a "Try it" simulator (SOC / price / minute → ON/OFF) to check rules before saving. 4 · ConsoleDense power-user panel: persistent status strip, grouped sidebar, master–detail logic editor with JSON diff, command palette (⌘K). 5 · Phone appNative-app feel: SOC charge ring, mode bottom sheet, rules as a vertical "battery ladder", settings as grouped drill-down lists.
